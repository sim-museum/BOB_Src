**S250 (backlog N3), 2026-08-25.** Generated by comparing every `SendMessage(WM_*)` call site in the
game sources against the compat dispatcher (`SRC/compat/bob_msgmap.cpp` + the hardcoded id checks in
`CWnd::SendMessageA`, `SRC/compat/afxwin.h`).

## Why this exists

Three distinct bugs in one MiG Alley session came from this class, which is what prompted the audit:

- a fix placed in `OnShowWindow` (a `WM_SHOWWINDOW` handler the compat never delivers) **silently did
  nothing** — the trace, not the code, is what revealed it;
- the *same* dead hook was the only caller of `SetDisabled(false)`, leaving a button visible but
  click-swallowed;
- a guard in one of **four** copies of `OnGetFile` blanked **732 of 1347** art fetches.

BoB's own S158 found `SendMessageA` was an allowlist of three answering 0 for everything else. This
audit asks: **what is still unreachable?**

## Result

The game sends **20 distinct `WM_*` types**. The dispatcher covers **7**.

## What this does and does not claim

It claims: **these nine handlers cannot currently be reached.** It does **not** claim nine visible
bugs — user-visible impact is unmeasured per route, and some handlers may be no-ops or serve paths
this port never enters. *An unreachable handler is a defect in the dispatcher; whether it is a defect
in the product depends on what the handler does.*

**One falsifiable prediction, cheap to test:** `WM_PLAYSOUND` has **17 send sites** in the R* controls
(combo, listbox, button). If it is genuinely unreachable, **UI click sounds are silent** while
in-flight audio works — the audio backend itself is fine (OpenAL, S6). If UI clicks *do* click, this
row is wrong and the audit needs a second look.

## How to regenerate

Compare `SendMessage(WM_*)` call sites under `SRC/` (excluding `SRC/compat/`) against the ids the
dispatcher answers; classify each miss by whether an `ON_MESSAGE(WM_*, handler)` exists in game code.

⭐ **The structural lesson, from MiG Alley S249:** BoB has ONE `OnGetFile` (`DIALCLASS::OnGetFile`,
macro-included three times), MA has FOUR hand-written copies — and MA's diverged. **A single
implementation instantiated per class makes divergence impossible rather than merely unlikely.**
Prefer that shape when repairing any of the routes above.
