### S20 — in-flight mouse (R5.2)
Full DirectInput→SDL mouse in compat (`bob_video.cpp`): `EnumDevices(MOUSE)`/`CreateDevice
(GUID_SysMouse)`/`EnumObjects` (2 relative axes + 3 buttons)/`SetDataFormat` offset-learning/
buffered `GetDeviceData` reading `SDL_GetRelativeMouseState`/`GetCaps`. Distinct non-zero
`GUID_SysMouse` (the R5.1 all-zero-`BOBGUID` keystone). Default-maps mouse axis 0→`AU_UI_X`,
1→`AU_UI_Y` so the in-3D cursor works out of the box (was `-0x8000` = disabled). Verified the
deltas reach `axisvalues[AU_UI_X/Y]` (sign + ratio match; no spurious drift when still).
**Keystone fix found along the way:** `DIDEV_EnumObjects` ignored the DIDFT type filter — the
controls-config's `EnumObjects(DIDFT_AXIS+DIDFT_POV)` counted buttons as axes → `firstaxes`
underflow → OOB write SIGSEGV. The joystick alone stayed under the bound (so R5.1 flight
worked); the mouse tipped it over. Now honours the filter; flight requests all types →
unregressed. `BOB_NOMOUSE`/`BOB_MOUSEFLY`/`BOB_TRACE_MOUSE`.

### S21 — controls config screen renders + game-wide CString-in-varargs fix (R5.3)
- A `BOB_CONFIGSCREEN` scaffold jumps straight to a config screen (`controls`/`gfx`/`gfx2`/
  `sound`/`2d`/`sim`/`load`) via the public `LaunchScreen` for headless render tests.
- The **Controls screen renders** (was a SIGSEGV) — validating the S20 EnumObjects fix in the
  front-end (`SController::BuildEnumerationTables` is exactly that `firstaxes` path).
- **The real prize:** the device/axis combo text came out as pointer garbage. Root cause: the
  engine pervasively writes `CSprintf("%s", aCString)` **without a `(LPCTSTR)` cast**. On MSVC a
  `CString` (one pointer member) is passed to varargs **by value** so `%s` reads the `char*`;
  under the **Itanium/SysV C++ ABI (Linux GCC)** a class with a non-trivial copy ctor/dtor is
  passed to varargs **by invisible reference** → `vsnprintf %s` prints the object's bytes →
  garbage. **Game-wide** (every `RESSTRING`/`LoadResString`/`.name` returns `CString`). Confirmed
  with a standalone `-m32` repro. **Fix** (`cstring_impl.cpp::FormatV`): pure-numeric formats keep
  trusted `vsnprintf`; only `%s` formats are token-parsed, resolving each `%s` arg as
  CString-by-ref vs `char*` by validating the `CStringData` header with `/proc/self/maps`-guarded
  reads. Bounded blast radius — only already-broken `%s` formats change. Lit up controls, all
  config tabs, and the debrief.

### S22 — controls rebind interactive (R5.3b)
The hosted combos cycle on click but that only changed the *display* — the reassignment lives in
`SController::OnTextChanged*` → `ChangedAxesCombo`, fired by the OCX **eventsink** which is a
no-op on Linux. A general eventsink would touch every dialog (vtable/macros), so a **targeted
`BOB_LINUX` bridge** was used: `SController::bob_combo_changed(ctrlId)` dispatches to the genuine
handler (X-macro list of 26 combos, compiler-validated); registered in `OnInitDialog`, called from
`bob_ole_click`. Verified: cycling the Stick combo changes its value **and recomputes the other
combos** (freed axes reappear as options elsewhere) — genuine interdependent reassignment;
persists via the unedited `PreDestroyPanel → SetAxisConfig`.

### S23 — load-game screen + save/load dependency (R6.5)
