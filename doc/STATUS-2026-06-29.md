## Historic-missions epic (PO-chose "full faithful fix") — in progress
Bailing historic QMs (23/25/27/28/29) have **two failure modes** (root-caused; `BOB_TRACE_PLAYERSQ` diag):
- **Mode 1 — "No player A/C"** (QM 23/25): out-of-range player squadron (168/208 > SQ_MAX); the player's
  own air group is skipped (S52) → `pilotedaircraft` NULL → FATAL.
- **Mode 2 — "Unresolved UIDS"** (QM 28): a pointer field holds `0x3fff` = `IllegalSepID` ("no reference"
  sentinel), wrongly queued for resolution → `anyoutstanding()` FATAL.

**Fixed so far — S70 `cb3a356`:** `setpointer` now treats `IllegalSepID`/`UID_NULL` as genuine NULL (no
queue, no `-1` placeholder). **QM 28 now passes the FATAL and reaches `View3d interactive`.** Verified safe
on core UID code (QM 11/26: 0 ASan errors; bare 0).
