This is a more detailed 109 skin set with various camouflage schemes selected according to the Staffel used (in the campaign game). 
It is an option as it may affect system performance.

To install:
You will see some subfolders: \imagemap \imgmap16 and \maskmap

Highlight and COPY these folders. Then PASTE them into your \rowan software\battle of britain\ folder. You will be asked to confirm 
that you wish to overwrite. 

If you want to get rid of them, then delete these files from the relevant directories.



This scheme is based on RLM colours 74, 75, 65 which was not common until the late battle period.
